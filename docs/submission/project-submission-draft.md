## プロジェクト概要

車椅子ユーザー向けバリアフリー旅行プランニングエージェント「michibiki」。行きたい場所と希望を伝えると、仮想の「旅のガイド」たちがGoogle Places APIの情報とレビュー・写真をGeminiで解析し、車椅子幅・段差などの個人条件と照らし合わせて「実際に入れるか」を理由付きで判定、一日の旅程を提案します。ユーザー専用のアバターを生成してガイドに反映し、体験写真もアバター本人として個人化。完成した旅程はVeoで動画化し、出発前に体験を疑似的に味わうこともできます。

## 課題と解決

**課題**

車椅子ユーザーは店舗の「バリアフリー対応」表記だけでは、実際に入店・利用できるか判断できないことが多くあります。段差・通路幅・多目的トイレの有無などをレビューや写真から都度確認するのは大きな負担です。また既存のバリアフリー情報サービスは情報提供にとどまり、「自分が行きたい場所」との掛け合わせ(パーソナライズ)が不足していました。

**解決アプローチ**

- 検索→判定→推薦の3エージェント構成を採用。Google Places APIで候補店舗を取得し、レビュー・写真をGeminiに読み込ませてバリアフリー度を判定
- ユーザーの車椅子幅・段差などの個人条件を保存し、判定時に数値根拠と突き合わせて「入れる／入れない／要確認」を理由付きで提示
- YouCam AI Avatarで生成した本人専用のアバターを旅のガイドとして個人化し、体験レポート画像にも反映(衣装やアートスタイルではなく顔・髪型のみを継承するようプロンプトを調整)
- 完成した旅程をVeoで動画化し、出発前の疑似体験を提供
- 旅の分析処理は非同期化し、クライアントはポーリングで結果を取得。低速回線や接続断でも結果を取りこぼさない設計に

## アーキテクチャ説明

**構成**

- フロントエンド: React (Vite) on Cloud Run
- backend-api: FastAPI on Cloud Run。Cloud SQL (PostgreSQL) で依頼・プロフィール・アバター・動画ジョブを永続化
- 検索・判定・推薦の3エージェント + trip-orchestratorをそれぞれ独立したCloud Runサービスとして分離
- persona-agent-backend: YouCam AI Avatar生成とGemini Live音声相談を担当する、DBアクセスを持たないステートレスな実行専用サービス
- video-agent: Veoで旅程全体の動画を生成

**利用AI技術**

Gemini(店舗のバリアフリー判定・推薦理由生成・体験写真生成)、Gemini Live(音声での旅の相談)、Veo(旅程動画生成)、YouCam AI Avatar(ユーザー専用アバター生成)

**設計上の工夫**

- アバター生成はYouCamの71スタイルから重複なしでランダム10種を選出し、使い切ったら削除して再抽選(v2)する方式で、毎回同じ見た目にならないようにした
- 各ガイドの体験写真に本人のアバターを反映する際、Geminiには顔・髪型のみを参照させ、アバターの衣装やファンタジー調のアートスタイルを引き継がないようプロンプトで明示的に制御
- 旅の分析はPOST直後に即時応答し、実処理はバックグラウンドで継続、フロントはポーリングで結果取得。長時間接続に依存しないため、ブラウザやネットワーク環境を問わず安定動作する

## 動作確認の方法

1. デプロイURLにアクセス(認証不要・個人情報の入力不要。ブラウザごとのランダムトークンで識別されます)
2. 「あなたの条件」画面で出発地・車椅子条件を確認(初期値のままでも動作します)
3. 「旅をつくる」から行き先・日時・してみたいことを入力して送信
4. 1〜2分ほどで旅のガイドたちが調べた結果・体験レポートが表示されます
5. (任意)プロフィール画面で写真をアップロードするとご自身のアバターを生成でき、スタイルの性別フィルタも選択できます
6. (任意)完成した旅程から動画生成を試すこともできます
