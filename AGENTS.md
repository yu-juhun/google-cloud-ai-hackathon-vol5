# Instructions for AI agents

Before doing any work in this repository, read [`docs/wiki/index.md`](docs/wiki/index.md).
It links to the project's steering page (`docs/wiki/concepts/steering.md`), which contains:

- what this project is and why (wheelchair-accessible restaurant recommendation agent)
- the hackathon's required GCP services and submission constraints
- team roles and ownership areas
- collaboration rules (branching, PR review, commit messages, Definition of Done, secrets)

This project follows the [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/open-knowledge-format)
for `docs/wiki/`. If a convention in `docs/wiki/schema.md` is unclear, refer to the official
spec (`SPEC.md` in that repo) rather than guessing.

Do not duplicate this content elsewhere — keep `docs/wiki/` the single source of truth and
update it (not just chat/PR descriptions) when you make a decision that affects other
contributors.
